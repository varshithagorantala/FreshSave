# FreshSave 🍱

FreshSave is a full-stack food rescue platform designed to reduce food wastage by connecting food providers with users in need.

## 🚀 Features
- User Registration & Login
- Food Listing & Request System
- Seller Approval/Rejection Workflow
- Admin Dashboard & Analytics
- Meals Rescued Tracking
- Responsive Mobile-Friendly UI

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Flask
- Flask-CORS

### Database
- SQLite3

## 📂 Project Structure

FreshSave/
│
├── backend/
├── frontend/
└── requirements.txt

## ▶️ Run Project

```bash
pip install -r requirements.txt
python backend/app.py
```

## 🌐 Default URL
http://127.0.0.1:5000
