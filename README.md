# 🥦 FreshSave — AI Food Rescue Platform

> Reducing food waste by connecting surplus food donors with people and NGOs in need — powered by AI expiry prediction.

---

## 🚀 About the Project

Every year, millions of tonnes of food go to waste while people go hungry. **FreshSave** tackles this problem by building a smart bridge between food donors (households, restaurants, stores) and recipients (NGOs, individuals) — before the food expires.

### Key Features

- 🤖 **AI-powered expiry prediction** — predicts when food items are likely to spoil and alerts users proactively
- 🔔 **Smart notifications** — automated reminders sent to users before food reaches expiry
- 🤝 **Donor-to-recipient matching** — connects food donors with nearby NGOs and individuals in need
- 🌐 **Web-based platform** — accessible from any device via browser

## ⚙️ Getting Started

### Prerequisites

- Python 3.x
- pip

### Installation

```bash
# Clone the repository
git clone https://github.com/DanishSami13/FreshSave.git
cd FreshSave

# Install dependencies
pip install -r requirements.txt

# Run the backend server
cd backend
python app.py
```

Then open `frontend/index.html` in your browser or serve it via a local server.

## 🌱 Why FreshSave?

Food waste is both a sustainability and a social equity problem. FreshSave was built as a 3rd-year B.Tech project to demonstrate how simple AI integration and thoughtful UX design can create real-world impact — reducing waste while feeding people who need it.
